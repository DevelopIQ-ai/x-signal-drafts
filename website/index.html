x-signal-drafts
GitHub npm

Don't miss the signal
on X

Pick the accounts you actually care about. x-signal-drafts watches them, skips the shitposts, and surfaces high-signal tweets with a draft reply you can review.

Free and open source. Runs on your own machine.

$ npx @puffle/x-signal-drafts serve

Needs Node 20+. Opens a local feed at http://127.0.0.1:3210.

Why you'd want this

Your own target list

Configure the exact people whose posts matter to you. No algorithm, no timeline noise, no trending tab.

Shitpost filter built in

A small model check keeps low-signal posts out of your feed. You only review the ones worth a reply or a reaction.

Nothing gets posted

It drafts, it alerts, it queues. It never logs into X or publishes on your behalf. You approve every reply.

Optional local UI

A feed page runs on your machine if you want it. Or run it headless and pipe alerts to your agent through stdout or email.

How it works

  1. 1

    Set your targets. Add the X handles you care about to config.json and copy .env.example to .env.

  2. 2

    Run it. x-signal-drafts run polls X, filters out low-signal posts, and appends alerts to a local feed.

  3. 3

    Review drafts. Open http://127.0.0.1:3210 to see the feed, or let your agent read the JSONL output and take it from there.

Try it locally

Install once, then start the local server and configure your targets.

$ npm install -g @puffle/x-signal-drafts && x-signal-drafts serve
  • • Needs an X API bearer token and an OpenAI key.
  • • Optional AgentMail variables send email alerts; otherwise they print to stdout.
  • • All state lives in data/ next to the binary.
